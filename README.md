# Beat 91 — Personal Offline Game

This folder is a complete static web/PWA project for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files and folders inside this folder** to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Click **Save**.
7. Wait a little, then open the Pages URL shown by GitHub.

The important entry file is `index.html`. Do not put the whole project inside an extra nested folder.

## Game data

The project contains the 6,365-player pool and the current V1.1 rating baseline.

## Note

The current ratings are an algorithmic playable baseline, not individually verified scouting grades. The game engine can be refined later without changing the GitHub Pages setup.
